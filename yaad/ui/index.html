Cloud processing for this folder

Yaad keeps your files and search index on this Mac. Text-layer PDFs and text documents are indexed locally. Yaad records request purpose, provider, status, latency, and token usage when available. Your API key and authorization headers are never shown.

About the Summary column

Summary names the source each cloud request relates to and the kind of content that was sent. Times in the table are shortened; select a summary in any row to see the full timestamp and the complete summary.
